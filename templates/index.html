Mini CDN Simulator

Distributed Content Delivery Through Edge Caching • CS-402 Project

Simulated Edge PoPs: 3 Online
How This CDN Simulator Works: When a request is submitted, the chosen Edge Cache is queried first. If the file is cached (CACHE HIT), it is immediately served from fast memory. If missing (CACHE MISS), the edge fetches the asset from the Origin Server, stores a copy in that edge's independent cache, and delivers it to the browser.
